# Управление таблицами

Программа позволяет создавать, просматривать и удалять таблицы базы данных. Информация о таблицах и типах их столбцов сохраняется в файле `db_meta.json`.

## Запуск программы

```bash
uv run project
```

Для перехода в режим управления таблицами введите команду:

```text
database
```

## Доступные команды

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу.
- `list_tables` — вывести список существующих таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `help` — вывести справочную информацию.
- `exit` — выйти из режима работы с таблицами.

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы столбец `ID:int` добавляется автоматически, если пользователь не указал его самостоятельно.

## Пример использования

```text
Введите команду: database
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана.

Введите команду: list_tables
- users

Введите команду: drop_table users
Таблица "users" успешно удалена.
```

Метаданные созданных таблиц сохраняются в `db_meta.json` и доступны после повторного запуска программы.
