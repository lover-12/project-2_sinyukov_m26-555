# Управление таблицами

Программа позволяет создавать, просматривать и удалять таблицы базы данных. Информация о таблицах и типах их столбцов сохраняется в файле `db_meta.json`.

## Запуск программы

```bash
uv run project
```

Для перехода в режим управления таблицами введите команду:

```text
database
```

## Доступные команды

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу.
- `list_tables` — вывести список существующих таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `help` — вывести справочную информацию.
- `exit` — выйти из режима работы с таблицами.

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы столбец `ID:int` добавляется автоматически, если пользователь не указал его самостоятельно.

## Пример использования

```text
Введите команду: database
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана.

Введите команду: list_tables
- users

Введите команду: drop_table users
Таблица "users" успешно удалена.
```

Метаданные созданных таблиц сохраняются в `db_meta.json` и доступны после повторного запуска программы.


## CRUD-операции

Программа поддерживает четыре основные операции для работы с записями таблиц: добавление (Create), чтение (Read), обновление (Update) и удаление (Delete).

Данные каждой таблицы хранятся в отдельном JSON-файле в директории `data/`. Например, записи таблицы `users` сохраняются в `data/users.json`.

### Добавление записей — INSERT

Команда:

`insert into <имя_таблицы> values (<значения>)`

Пример:

```text
insert into users values ("Sergei", 28, true)
```

Программа проверяет количество значений и их типы, автоматически генерирует ID и сохраняет запись.

### Просмотр записей — SELECT

Для просмотра всех записей:

```text
select from users
```

Для просмотра записей по условию:

```text
select from users where age = 28
```

Результаты отображаются в виде таблицы с помощью библиотеки PrettyTable.

### Обновление записей — UPDATE

Команда:

`update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>`

Пример:

```text
update users set age = 29 where ID = 1
```

Программа находит подходящие записи и обновляет указанный столбец. Тип нового значения проверяется по схеме таблицы.

### Удаление записей — DELETE

Команда:

`delete from <имя_таблицы> where <столбец> = <значение>`

Пример:

```text
delete from users where ID = 1
```

Программа удаляет записи, соответствующие условию.

### Информация о таблице — INFO

Команда:

```text
info users
```

Выводит название таблицы, список столбцов с типами данных и количество записей.

### Пример полного цикла CRUD

Сначала создайте таблицу:

```text
create_table users name:str age:int is_active:bool
```

Затем выполните:

```text
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where ID = 1
select from users
delete from users where ID = 1
info users
```

Для строковых значений необходимо использовать двойные кавычки. Поддерживаются типы `int`, `str` и `bool`. Изменения записей сохраняются в JSON-файлах.
## Декораторы и кеширование

В программе реализованы декораторы для обработки ошибок, подтверждения опасных операций и измерения времени выполнения функций. Для кеширования результатов запросов используется замыкание.

### Обработка ошибок — `handle_db_errors`

Декоратор `handle_db_errors` применяется к функциям работы с базой данных и обрабатывает исключения:

- `KeyError` — отсутствие необходимого ключа.
- `ValueError` — некорректные значения и типы данных.
- `FileNotFoundError` — отсутствие файла.

При возникновении ошибки выводится сообщение, а программа продолжает работу.

### Подтверждение операций — `confirm_action`

Перед удалением таблиц и записей программа запрашивает подтверждение пользователя.

Пример:

```text
Введите команду: drop_table products
Вы уверены, что хотите "удалить таблицу"? [y/n]: n
Операция отменена.
```

При ответе `y` операция выполняется, при `n` — отменяется без изменения данных.

Декоратор применяется к функциям `drop_table()` и `delete()`.

### Измерение времени — `log_time`

Декоратор `log_time` измеряет продолжительность выполнения функций с помощью `time.monotonic()`.

Пример вывода:

```text
Функция select выполнилась за 0.000012 секунды.
```

Декоратор используется для операций `insert()` и `select()`.

### Кеширование через замыкание — `create_cacher`

Для хранения результатов запросов `select` используется замыкание `create_cacher()`.

При первом запросе программа выполняет выборку и сохраняет результат в кеше. При повторном одинаковом запросе данные берутся из кеша без повторного выполнения `select()`.

После успешного добавления, обновления или удаления записей кеш очищается. Это позволяет получать актуальные данные после изменений таблицы.
